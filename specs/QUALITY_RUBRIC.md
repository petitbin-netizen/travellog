# 정성 규율 10가지 — 루프 C가 매 회차 점검하는 것 (핀터레스트 감성)

이 문서는 **직접 고르는 문서가 아닙니다.** 킷이 정해 둔 고정 규율입니다.
`MASTER_SPEC.md`의 `quality_contract.rules`가 여기 있는 ID를 그대로 가리킵니다.

| 문서 규칙 | 결정 장부 | 화면 계약 |
| --- | --- | --- |
| [00_INDEX](00_INDEX.md) | [00_DECISION_LOG](00_DECISION_LOG.md) | [02_PAGE_DESIGN](02_PAGE_DESIGN.md) |

---

## 1. 왜 이 문서가 있나

루프 A와 루프 B는 **셀 수 있는 것**만 봅니다 (필드가 있는가, 카드 개수가 맞는가).
"핀터레스트 감성"처럼 눈으로 봐야 아는 것은 그걸로 못 잡습니다. 그래서 루프 C가 있습니다.

---

## 2. 규율 10가지

| ID | 무엇을 보나 | 위반이면 무엇을 고치나 |
| --- | --- | --- |
| `Q-그리드정렬` | 목록 화면이 매소너리(또는 균등) 그리드로 자연스럽게 배치되는가, 카드가 어긋나거나 겹치지 않는가 | 그리드 CSS를 다시 잡는다 |
| `Q-이미지우선` | 카드에서 이미지가 시각적으로 가장 먼저 보이는가 (텍스트가 이미지를 압도하지 않는가) | 레이아웃 비율을 이미지 중심으로 조정 |
| `Q-여백감각` | 섹션·카드 사이 여백이 답답하지 않은가 (핀터레스트 특유의 숨 쉬는 간격) | 여백 값을 늘린다 |
| `Q-호버반응` | 카드에 마우스를 올렸을 때 살짝 확대·그림자 등 반응이 있는가 | 호버 트랜지션을 추가 |
| `Q-팔레트일관` | 페이지 전체가 정한 팔레트(배경·텍스트·포인트 컬러 1개)를 벗어나지 않는가 | 색상을 팔레트로 통일 |
| `Q-빈기록처리` | 이미지·지도(day.map_url)·장소·코멘트가 없는 날/기록도 어색하지 않게(placeholder로) 보이는가 | placeholder 처리를 보강 |
| `Q-지도가독성` | day.map_url이 있는 날짜 카드의 지도(임베드/링크)가 그 날짜 안에서 눈에 띄고, 어떤 동작인지 예측 가능한가 | 지도 영역 UI를 명확히 |
| `Q-타임라인가독` | 날짜 타임라인이 시간순으로 읽히고, 각 날짜와 그 안의 장소들이 구분되는가 | 타임라인 마크업을 정리 |
| `Q-코멘트가독` | 코멘트가 본문과 시각적으로 구분되어 "메모"처럼 읽히는가 | 코멘트 스타일을 구분 |
| `Q-계약무결` | 이번 회차 수정이 `data-*` 계약·필수 필드 렌더링을 훼손하지 않았는가 | 훼손된 부분을 되돌림 |

> `Q-계약무결`만 성격이 다릅니다. 나머지 아홉이 **결과물을 좋게 만드는 규율**이라면,
> 이것은 **좋게 만들다가 계약을 깨뜨리지 않았는지** 보는 규율입니다.

---

## 3. 회차마다 렌즈가 다르다

| 회차 | 렌즈 | 그 회차의 초점 |
| --- | --- | --- |
| **1** | 시각적 기본기 | `Q-그리드정렬` `Q-이미지우선` `Q-여백감각` `Q-팔레트일관` |
| **2** | 상호작용과 예외 | `Q-호버반응` `Q-빈기록처리` `Q-지도가독성` |
| **3** | 정보 가독성과 계약 유지 | `Q-타임라인가독` `Q-코멘트가독` `Q-계약무결` + 앞 두 회차가 되돌아가지 않았는지 |

매 회차 10개를 전부 판정하되, 그 회차의 초점 4개(또는 3개)를 우선 고칩니다.

---

## 4. 회차마다 남기는 것 (형식 고정)

```text
evidence/runs/<run_id>/quality/pass1.json
evidence/runs/<run_id>/quality/pass2.json
evidence/runs/<run_id>/quality/pass3.json
```

`scripts/check_quality_passes.py`가 이 파일들을 읽어 판정합니다.

---

## 5. 판정기가 보는 것과 보지 않는 것

```text
보지 않는다   디자인이 몇 점인가        ← 점수를 매기지 않는다
본다         3회를 다 돌았는가
본다         회차마다 10개를 전부 판정했는가
본다         위반이라 적은 것을 실제로 고쳤는가
본다         고쳤다면 파일이 실제로 바뀌었는가
본다         회차 끝마다 루프 A·B가 여전히 통과하는가
```

---

## 6. 되돌리기 규칙

정성 수정이 정량 계약(루프 A·B)을 깨뜨리면 **그 회차의 수정을 되돌립니다.**

```bash
python scripts/verify_all.py --skip-quality      # 회차 끝마다 반드시
```
